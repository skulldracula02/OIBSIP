# Unit Converter App

A simple Android app built with Java and XML that converts values across length, weight, and temperature units.

## Features
- Numeric input field
- Category selector for Length, Weight, and Temperature
- Source and target unit spinners
- Convert button with result display
- Toast validation for empty or invalid input

## Run in Android Studio
1. Open the project folder in Android Studio.
2. Let Gradle sync complete.
3. Select a device or emulator.
4. Run the app.
