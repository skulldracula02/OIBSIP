# To-Do Web App

Simple vanilla JavaScript to-do application.

Features:
- Add tasks
- Edit tasks inline
- Mark complete / undo
- Delete tasks
- Pending / Completed lists with counts
- Timestamps for added/completed
- Persistence via `localStorage`
- Empty-state messages

Run:
1. Open `index.html` in a browser (double-click or use a local server).

Notes:
- Data persists in browser `localStorage` under the key `todoApp.tasks`.
- This is a minimal, single-file JS app — no build steps required.
